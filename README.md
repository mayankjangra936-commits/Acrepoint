
# AcrePoint – Real Estate Website

AcrePoint is a modern and responsive **Real Estate Website** built using **HTML and CSS**.  
It includes multiple pages such as Home, Properties, About, and Contact, providing a clean and professional user experience.

---

## 🚀 Features

- Fully responsive layout  
- Modern UI design  
- Homepage with hero banner  
- Property listings page  
- About us section  
- Contact form  
- Clean navigation bar and footer  
- Built using pure **HTML + CSS**

---
